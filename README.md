# Job Search Assistant

Workspace для поиска работы на базе [Claude Code](https://claude.com/claude-code). Содержит скиллы для написания резюме и откликов, HTML-шаблон с генерацией PDF и опциональный агент для ежедневного поиска вакансий.

## Структура

| Путь | Назначение |
|------|-----------|
| `resumes/` | Резюме пользователя в PDF и Markdown. Читаются агентом при каждой сессии. |
| `jobs/` | Ежедневные отчёты `YYYY-MM-DD.md` с найденными вакансиями. |
| `applications/` | Архив откликов. Один Markdown-файл на вакансию: URL, статус, история переписки, заметки. |
| `.agents/skills/` | Скиллы агента: правила, шаблоны, примеры. Загружаются по триггеру. |
| `daily-search-jobs.md` | Промт для агента ежедневного поиска вакансий. |
| `CLAUDE.md` | Главный файл проектных инструкций для Claude Code. |

## Требования

- Claude Code CLI
- Python 3 с пакетом `weasyprint` (сборка PDF из HTML-шаблона)
- Git
- GitHub Actions или cron (опционально, для ежедневного агента)

## Установка

```bash
git clone <repo>
cd job-search
pip install weasyprint
claude
```

При первом запуске агент проверяет `resumes/`. Если резюме отсутствует, задаются вопросы о целевой роли, стеке, опыте, формате работы, рынках и языке общения. Ответы определяют поведение всех последующих задач.

## Скиллы

### `resume`

Скилл для написания и редактирования резюме.

- Каждый bullet point по формуле Google XYZ: *Accomplished X, measured by Y, by doing Z*
- HTML-шаблон двухколоночного резюме формата A4 (`templates/two-column.html`)
- Сборка PDF через WeasyPrint (`scripts/build-pdf.py`)
- База примеров переписанных bullets на русском и английском (`examples/bullets.md`)

Триггеры: упоминание резюме, CV, cover letter, или вызов `/resume`.

### `application`

Скилл для написания откликов на вакансии и ответов рекрутёрам.

- Подстройка тона ответа под стиль исходного сообщения (casual / friendly / business / direct)
- Запрет признаков AI-генерации: em dash, стрелки, markdown-форматирование в чат-сообщениях
- Автосохранение каждого отклика в `applications/` с метаданными вакансии
- Дозапись фоллоу-апов в существующий файл при multi-turn переписке

Триггеры: упоминание отклика, ответа рекрутёру, cover message.

## Ежедневный поиск вакансий

`daily-search-jobs.md` содержит промт для агента поиска. Скрипт `run-job-search.sh` — пример точки входа для запуска через cron или GitHub Actions.

Источники: hh.ru, Habr Career, Hirify, GetMatch, web3.career, Bondex, публичные Telegram-каналы.

Результаты сохраняются в `jobs/YYYY-MM-DD.md` и коммитятся в репозиторий.

## Конфигурация

| Что менять | Где |
|-----------|-----|
| Дизайн резюме | `.agents/skills/resume/templates/two-column.html` |
| Правила откликов | `.agents/skills/application/SKILL.md` |
| Источники вакансий и фильтры | `daily-search-jobs.md` |
| Профиль пользователя и общие правила | `CLAUDE.md` |

## Безопасность

Репозиторий не хранит:
- API-ключи (используется авторизация Claude Code)
- Историю диалогов с Claude (`~/.claude/`)
- Сторонние секреты

В `applications/` находятся тексты откликов и переписки с рекрутёрами. Перед публикацией репозитория содержимое директории следует проверить.

## Лицензия

Личный инструмент. Использование, форк, модификация — свободно.
